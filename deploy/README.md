# Deployment

This directory will document the deployment strategy for FlightRisk AI.

Planned deployment topics include:

- Docker containerization
- Local application startup
- Blue-green deployment design
- Model versioning
- Scaling strategy
- Load balancing
- Rollback procedures
- AWS or Microsoft Azure architecture

The final project will include an architecture diagram showing how the web interface, REST API, model service, containers, and cloud components interact.

# Models

This directory will document the machine learning models developed for FlightRisk AI.

The project will compare four primary modeling approaches:

- Two deep learning models
- Two interpretable or explainable machine learning models

This directory may contain lightweight model metadata, configuration information, and documentation.

Large trained model files will not be stored directly in GitHub. They will be excluded using `.gitignore` and documented so the project can be reproduced.

Planned model artifacts may include:

- Model version information
- Training configuration
- Evaluation summaries
- Feature lists
- Model selection notes
- Deployment model metadata
